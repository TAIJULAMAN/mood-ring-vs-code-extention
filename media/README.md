# Audio Assets

Place the following files in this directory:

- `flow.mp3`: A low, ambient hum or synth drone for the "Flow" state.
- `panic.mp3`: A heartbeat sound for the "Panic" state.
- `silence.mp3`: Optional, used if we want to play silence explicitly.

Note: The extension uses `flow.mp3` and `panic.mp3` by default.
